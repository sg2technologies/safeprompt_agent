File uploads that can't be masked

"Mask it" above only redacts a value in place for plain-text files (.txt, .csv, .md, .json, .log, .yaml, .xml, .html) — the file's content is its own text, so nothing is lost replacing just the matched value. A .docx, PDF, or image has real structure (formatting, layout, pixels) that gets thrown away extracting text from it, so writing masked text back as the file would corrupt it. Install it (one-time, ~1 minute)

On a personal (non-domain / non-Intune) machine Chrome and Edge block silent extension installs, so this is done by hand once. It stays installed after that.

  1. Open chrome://extensions (or edge://extensions) in a new tab
  2. Turn on Developer mode (top-right toggle)
  3. Click Load unpacked
  4. Select this folder:
    C:\Program Files\SafePrompt\extension\unpacked
  5. Reload this page — the status above should turn to detected within a minute or two

On Chrome/Edge the extension talks to this agent automatically. Nothing else to configure.
